# Local hairline figures

Figures drawn for this prototype with Thiago Andrade's `tomtom-hairline` skill
(https://github.com/thiagoandrade-tomtom/tomtom-docs-illustrations), in the same
format as `public/hairline/figures/`. They live here, not in `public/hairline/`,
because `scripts/sync-hairline.sh` replaces that folder wholesale.

`src/illustrations/hairline.jsx` loads a slug under `nav/` from this folder.
Once a figure is accepted upstream, move its mapping to the upstream slug and
delete it here.
